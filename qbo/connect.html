AXIS QuickBooks connect / reconnect

Use this page when Intuit asks for a Connect or Reconnect URL for AXIS’s private QuickBooks Online app.

Reconnect is an operator procedure (not a public signup):

  1. Ensure Production Client ID/Secret are in the AXIS production token store (never in chat or source).
  2. Register an exact HTTPS /callback redirect URI in Intuit Production Redirect URIs.
  3. Run the AXIS production OAuth script with the matching redirect, complete browser consent + MFA as Jorge.
  4. Confirm refresh token and realm ID were written to the production token store (lengths only), then use the read-only AXIS-QBO-Production MCP.
